## 二、怎么读这些数

**可以做的比较**：同一管线、同一口径下的例间比较。b02 的 Δp 是 b01 的 2.8 倍、R 是 2.8 倍，而它的出口面积最小（84.57 mm²）、WSS 最大最高（22.865 Pa），三者方向一致——这是内部自洽的，说明 b02 的鼻腔整体更窄。这类相对判断是站得住的。

**不能做的比较**：

1. **R 绝对值 vs 临床鼻测压**。ISCOANA 正常参考约 0.25 Pa·s/mL，三例都远低于它。这不是"患者通气好"，是**层流低估 + 域在口咽底截断缺下咽喉阻力**，两层系统性偏低。方向已知，幅度未知。
2. **出口面积 vs choana 文献带**。文献带 297–362 mm² 适用于解剖 choana，我们的出口是扫描底工程截断面，不是同一个东西。
3. **跨口径混比**。轴位切与解剖切、短域与扩展域的数都保留在 `metrics.json` 的 `note` 里作追溯，但**新旧不可比**。把 18.267 和 17.120 放在一张表里比"改进"是错的——它们是两个几何。

## 三、三例之间的关系

- **b15**：轴位切与解剖切都有，是唯一能做出口口径 A/B 的例。入口侧逐位复现，出口侧面积 +13.4%、Δp −6.28%。
- **b01**：同样有两套口径。出口面积变化最大（148.93 → 208.46，+40%），但 Δp 只变 1.58%——因为它的出口段在总阻力里占比低。**面积变化大不等于压降变化大**，这条容易被误读。
- **b02**：首次进求解链，没有轴位切基线，这批数就是它的首产基线。三例中 Δp / R / WSS 全最高。

## 四、明确没有的

| 缺什么 | 为什么 |
|---|---|
| 患者级温湿度 / 热通量 | 取值截面须在后鼻孔而非域出口，尚未按新截面重跑 |
| 正常人参考队列 | 未建立，因此没有患者 vs 正常人的分组对照 |
| k-ω SST 结果 | 当前网格跑不通（非正交 76.56°、det<0.001 计 482） |
| 自然分流结果 | 口径未实现，三例均为固定 50:50 |
| 三例以外的求解 | 几何层过了 24 例，求解层只有这三例 |

**以上缺项一律标"—"，不填估算值。** 需求书里"鼻甲区低速死区""气流分布均匀性"这类 ENS 专用指标，我们有原始场数据但尚未定义出可复现的量化口径，所以本轮不出数。

## 五、复验方式

改任何判据后必须先跑基准再谈结论：

```bash
python src/pipeline/nasal_pipeline.py --cases b01 b15 b02 --skip-series --from-stage 3
```

通过的判定不是"跑完了"，是**入口侧面积逐位不变**（b15 左鼻孔 80.03741 mm²、右 80.05729 mm²）且 `N6.provenance == match`。任一不符即视为几何被改动，需先定位再继续。
