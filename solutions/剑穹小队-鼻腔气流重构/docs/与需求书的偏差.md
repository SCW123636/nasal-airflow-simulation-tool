# 与需求书的偏差说明

对照依据：《空鼻症（ENS）鼻腔气流重构分析工具 产品需求书 V1.0》（2026-10-01）第四节「关键技术参数」与「输出指标」。

原则：**有偏差的地方写清楚为什么改、影响是什么、代价由谁承担**，不把偏差包装成实现细节。

## 一、一致的部分（先说不争的）

| 项 | 需求书 | 本项目 | 状态 |
|---|---|---|---|
| 入口流量 | 静息呼吸约 15 L/min（双侧合计） | 15 L/min，双侧各 7.5 L/min | ✅ 一致 |
| 出口压力 | Pressure outlet = 0 | p = 0（gauge） | ✅ 一致 |
| 壁面 | 无滑移 | 无滑移 | ✅ 一致 |
| 鼻阻力定义 | 进出口压差 ÷ 流量 | Δp / Q，单位 Pa·s/mL | ✅ 一致 |
| 分割阈值 | 空气 −1024 至 −300（按实际微调） | −300 | ✅ 在区间内 |
| 鼻窦 / 鼻泪管 / 咽鼓管 | 一律排除 | 只取鼻腔 + 鼻咽 + 口咽，鼻窦不纳入 | ✅ 一致 |

## 二、偏差清单

### 偏差 1（主要）：出口位置 —— 解剖斜切，不是冠状面

| | 需求书 | 本项目 |
|---|---|---|
| 切面方向 | **沿冠状面切平整** | **垂直局部气道轴**斜切（拟合自切口向上 10 mm 的气道轴） |
| 位置基准 | **软腭游离缘水平**，全病例统一 | 平面最低点 = 底孔中心 + 0.5 mm，跟着扫描走 |
| 实测倾角 | — | 23.71° / 24.36° / 24.75°（b15 / b01 / b02） |

**为什么改**：

1. 冠状面是**人体坐标系**的平面，不是**气道**的平面。气道在鼻咽—口咽段本身是前倾的，用冠状面切等于斜着切断流道，出口截面会变成椭圆，面积被高估（横截面积 × 1/cosθ）。
2. 「软腭游离缘水平」这个基准要求软腭可稳定识别。实测 24 例里 22 例软腭触及扫描上界（颈部长度扫描时软腭就在 FOV 上界），**基准点本身不稳定**，无法做到"全病例统一"。
3. 垂直气道轴切出来的截面才近似真实过流断面，出口流速与 WSS 的分布才有物理意义。

**影响**（全部有实测对照）：

| 例 | 轴位切出口面积 | 解剖切出口面积 | Δp 变化 |
|---|---|---|---|
| b15 | 111.00 mm² | 125.85 mm²（+13.4%） | 18.267 → 17.120 Pa（−6.28%） |
| b01 | 148.93 mm² | 208.46 mm²（+40.0%） | 15.709 → 15.460 Pa（−1.58%） |
| b02 | 91.98 mm² | 84.57 mm²（−8.1%） | 无轴位切基线 |

**入口侧三例逐位复现**（b15 鼻孔 80.03741 / 80.05729 mm² 等），说明改动只作用在出口，入口零扰动——这是这次改动的回归锚。

**代价**：出口面积从"可对上文献带"变成"工程属性"。面积绝对值不能再和 choana 文献带（297–362 mm²）比较。**换来了可比的流场**，失去了可比的面**。我们认为值得，因为需求书的目的是比气流而不是比面积。

### 偏差 2：计算域延伸到可见口咽

| | 需求书 | 本项目 |
|---|---|---|
| 域下限 | 鼻咽出口 | 鼻咽 + 可见口咽，在扫描 FOV 底面工程截断 |

**为什么**：只算到鼻咽会让出口边界压在流场仍然剧烈变化的区域上，出口条件反过来污染上游。向下多扩一段，出口才落在相对平缓的位置。

**影响**：容积变大（b15 21.33 mL），压降比短域高（b15 短域 10.286 → 扩展域 17.120 Pa，**短域低估 40%**）。这说明短域不是"简化"，是"算错方向"。但域再往下就出扫描范围了，所以是截断而不是完整气道。

### 偏差 3：湍流模型 —— 层流，不是 k-ω SST

| | 需求书 | 本项目 |
|---|---|---|
| 定量推荐 | k-ω SST | 层流 |
| 入门 | Laminar 跑通 | 层流，已跑通 |

**为什么**：当前网格非正交度最大 76.56°、det<0.001 的单元 482 个（b15），k-ω SST 在这套网格上没有跑通。雷诺数约 1000–2500 落在层流到过渡区间，层流可作工程筛查，但不是最终答案。

**影响**：压降与 WSS 系统性偏低（层流缺湍流附加应力）。**这也正是 R 绝对值不能对标临床的原因之一。**

**没有做的事**：我们没有把 k-ω 的失败说成"层流更准"。层流是能力边界，不是选择。

### 偏差 4：分流口径 —— 固定 50:50

| | 需求书 | 本项目 |
|---|---|---|
| 左右分配 | 未规定 | 固定各 7.5 L/min |

**为什么**：固定分流是给定边界条件最简单、最可复现的形式，先让链路跑通。

**影响**：真实鼻腔左右流量按阻力自动分配，通常不是 50:50。自然分流口径（按出口压力反馈调分配）尚未实现。**它会让左右流量分配更接近生理，但会让"同一例换口径"的数不可直接比。**目前三例都是固定分流，例间可比。

### 偏差 5：温湿度 / 热通量未出患者级结果

需求书把温湿度列为「进阶」指标。我们的合成验证已通过（残差 9.76e-13），但取值截面经裁定应为**后鼻孔**而非域出口，患者级尚未按该截面重跑。**当前如实标"—"，不填估算值。**

## 三、没有偏差但需要说明的两件事

**1. 表面面数**。需求书建议 3 万–10 万面。我们的 STL 面数随网格分辨率走，未做 30–50% 简化。原因是简化会引入非流形与退化面，而下游是体网格不是渲染，面数不是质量指标。**这一条是"未按建议执行"，不是"结果不符"。**

**2. 医学复核**。本项目所有产物带 `clinical_status: generalisation_test_only_no_human_review`。自动通过只保证开口面积合理，**位置正确性未做人体复核**，也不声称做过。需求书「不能单独用于诊断、决定手术方案」的边界，我们照此执行并写进许可证。
